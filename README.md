# Codora

Application mobile-first d'apprentissage du développement web, en français.

## Parcours
- HTML : 10 leçons
- CSS : 11 leçons
- JavaScript : 11 leçons
- Exercices interactifs à chaque leçon
- Progression sauvegardée localement dans le navigateur
- Navigation : Accueil, Parcours, Pratique, Profil
- Interface sombre, sans publicité, abonnement, Premium, monnaie ou classement

## Lancer en local

```bash
npm install
npm run dev
```

Puis ouvrir l'adresse locale indiquée par Vite.

## Mise à jour

Modifie les fichiers du projet puis republie le projet avec ton hébergeur. Les données de progression sont stockées localement sur l'appareil de l'utilisateur.
